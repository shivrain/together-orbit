# Together Orbit

Temporary public demo of Together Fund's portfolio sourcing dashboard.

- Referral inbox: explore fictional introductions, change conversation stages, and add browser-local referrals.
- Portfolio monitoring: review the company-by-company example report and export it. No live scans are performed.
- Founder engagement: browse sourced resources, save drafts locally, copy them, or open them in an email app.

All edits are saved in the visitor's own browser. Data is not shared between teammates. Live Gmail synchronization, scheduled scans, and people-data providers require a separate authenticated backend and are not connected to this demo.

This repository contains the static publication only. No production records or credentials are included.
