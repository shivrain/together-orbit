# Together Orbit

GitHub Pages entry point for Together Fund's complete portfolio sourcing application.

Open: https://shivrain.github.io/together-orbit/

The entry point opens the full application at https://together-orbit.together-fun-4175.chatgpt.site/ . Its original interface, shared records, report history, backend APIs, and integration setup are preserved. GitHub Pages does not execute the backend.

The application is publicly accessible, as requested by its owner. Existing integration setup requirements still apply; publication does not connect Gmail or a people-data provider.
